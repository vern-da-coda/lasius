Measurement datasets, empirical potentiometer benchmarks, and runtime calibration snapshots for the **Lasius** 18-DOF Hexapod robot.

## Directory Organization

```text
data/
├── bench/                   # Empirical bench measurements & calibration curves
│   ├── servo_ch15_pot_calibration.csv   # Raw ADC / potentiometer voltage samples
│   ├── servo_ch15_pot_calibration.json  # Fitted linear/polynomial regression parameters
│   └── README.md                        # Calibration methodology and bench test instructions
└── calibration_backups/     # Local timestamped calibration snapshots (.gitignore)
    └── .gitkeep             # Directory placeholder
```

---

## Subdirectories

- [**`bench/`**](bench/README.md):
  Contains experimental calibration sweeps generated by [`scripts/bench/pot_calibration_wizard.py`](../scripts/bench/pot_calibration_wizard.py) and [`scripts/bench/servo_pot_sweep.py`](../scripts/bench/servo_pot_sweep.py). Used to calibrate ADC readings from internal servo potentiometers into precise joint angles.
- [**`calibration_backups/`**](calibration_backups/README.md):
  Stores timestamped snapshots of `calibration.json` fetched from the physical robot via [`scripts/deploy/backup_calibration.sh`](../scripts/deploy/backup_calibration.sh). All `.json` files in this directory are excluded from version control via `.gitignore`.

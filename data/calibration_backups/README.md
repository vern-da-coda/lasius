Local timestamped calibration snapshots retrieved from the physical Raspberry Pi via [`scripts/deploy/backup_calibration.sh`](../../scripts/deploy/backup_calibration.sh).

These JSON files store runtime potentiometer regression models and calibrated PWM servo endpoints for all 18 robot joints.
